OPEN IT
1. Extract the ZIP into a normal folder.
2. Keep all files and folders together.
3. Open index.html in a browser to preview the website.

EDIT THE SITE
Open js/data.js in VS Code or a text editor. It controls profile details, social links, focus areas, projects, blog articles and YouTube videos. Save changes and refresh the browser.

PROFESSIONAL DETAILS
Read PROFESSIONAL-DETAILS-WORKSHEET.md to prepare your bio, education, experience, skills, certificates, projects and public profile links.
Read EDITING-GUIDE.md for detailed step-by-step instructions.

PAGES AND FEATURES
Home · About · Education · Expandable experience timeline · Certifications & professional development · Filterable skills · Projects · Project case studies · Blog · Article pages · Vlog · Contact.
Search and category filters; clickable focus areas; dedicated case studies/articles; responsive mobile navigation; dark/light mode; YouTube embeds after video IDs are added.

FREE HOSTING
This is a static website with no paid framework, server or database. It can be deployed to a free static host. A host-provided address can be used before you consider buying a custom domain.

Before publishing, review draft articles and ensure project descriptions are accurate. Email, telephone details, LinkedIn, GitHub, Hack The Box and TryHackMe profile links have been added. The experience responsibility bullets in the About page are explicitly marked as drafts and must be checked against your real duties before you publish them. Certificate titles, issuers and dates reflect the details supplied for this site; add public verification links if available. Do not publish private or sensitive information.
